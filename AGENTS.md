# AGENTS.md

This Java and Maven project contains several independent modules:

- spring-ai-basics: Spring Boot command-line application using Spring AI to perform various tasks
- spring-ai-chatbot: Spring Boot web application using Spring AI to implement a basic chatbot
- spring-ai-mcp-server: Spring Boot using Spring AI to implement an MCP server with several tools and an MCP App
- spring-ai-mcp-client: Spring Boot command-line application using Spring AI to implement an MCP client that connects to the previous MCP server
